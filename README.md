# Il mio piano

App per la dieta (lunedì–venerdì): pranzo in mensa, cena adattata al pranzo
secondo il piano della nutrizionista, ricette e lista della spesa.

- `index.html`: l'intera app, un solo file (HTML, CSS e JavaScript, nessuna dipendenza).
- Grafica in stile app Salute di iPhone, chiara e scura.
- I dati personali non sono nel codice: restano salvati sul dispositivo o sull'account Claude.

Versione online (Claude): https://claude.ai/artifact/CDDHKJThkRWQHwZhCkxLB8

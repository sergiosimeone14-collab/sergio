# Il mio piano

App per la dieta (lunedì–venerdì): pranzo in mensa, cena adattata al pranzo
secondo il piano della nutrizionista, ricette e lista della spesa.

- `index.html`: l'intera app (HTML, CSS e JavaScript, nessuna dipendenza esterna).
- `manifest.webmanifest`, `icons/`: nome e icona quando la aggiungi alla schermata Home.
- `sw.js`: fa funzionare l'app anche senza connessione.
- Grafica in stile app Salute di iPhone, chiara e scura.
- I dati personali non sono nel codice: restano salvati sul telefono.

## Pubblicazione

GitHub Pages, dal ramo `main`, cartella principale.
Si apre in Safari e si aggiunge alla Home con Condividi → Aggiungi alla schermata Home.

## Portare i dati dalla versione su Claude

1. Nella versione su Claude: impostazioni (cerchio "SS") → Copia i miei dati.
2. Nella nuova app: impostazioni → Importa dati → incolla → Importa.
